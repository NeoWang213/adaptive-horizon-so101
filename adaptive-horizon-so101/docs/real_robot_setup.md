# 实机配置：待补充

计划平台为 SO-ARM101，任务为物块放盒与笔放笔筒。
本页预留正式配置与部署说明；当前不提供未经验证的实机命令。

后续上传模型与代码时，请补充：

- 机械臂型号、标定方式、关节顺序/单位和控制频率。
- 相机型号、数量、位置、图像分辨率及观测键名。
- Python、PyTorch、CUDA、驱动及实际使用的 LeRobot/π0.5 版本。
- ACT 与 π0.5 各自的 checkpoint、输入处理、动作输出和任务提示词。
- 动作块长度、执行长度范围、MLP 权重及对应配置。
- 动作缓存切换、episode 重置和中断处理方式。
- 已验证的安装、训练、部署和最小示例命令。

串口、相机编号、个人路径和本机标定文件应通过示例配置解释，避免把本机值写成
通用默认值。模型和数据的具体下载地址由各目录的资源清单记录。

如需使用 SO-ARM101 的外部 CAD/URDF，记录
[SO-ARM100 项目](https://github.com/TheRobotStudio/SO-ARM100)的具体版本，并保留其许可。
