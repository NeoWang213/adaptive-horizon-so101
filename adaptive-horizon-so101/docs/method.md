# 方法设想

本项目研究在 SO-ARM101 上，根据任务当前状态自适应选择动作执行长度。
基础策略为 ACT 和微调后的 π0.5，分别接入、分别评估。

## 基本流程

1. 获取机器人状态和相机观测。
2. 基础策略预测固定长度的动作块。
3. 轻量 MLP 利用当前可获得的特征选择执行步数。
4. 执行所选动作前缀后，获取新观测并再次调用策略。

这里调整的是执行长度 `execution_horizon`。基础策略一次预测的动作块长度
`chunk_size` 是另一个参数。MLP 必须选择当前动作块中实际可执行的长度。

## 待确定和上传的内容

| 项目 | 待补充 |
|---|---|
| 输入特征 | 机器人状态、动作块统计或可复用策略表征等候选输入的比较 |
| 监督目标 | Horizon 标签生成规则、标注依据及局限 |
| 网络结构 | MLP 输入维度、隐藏层、输出形式 |
| 候选长度 | 随控制频率与策略动作块长度确定 |
| 训练设置 | 数据划分、超参数、种子、模型选择方式 |
| ACT 接入 | 特征提取、动作前缀执行、缓存与重置方式 |
| π0.5 接入 | 实际后端、处理器、特征与动作接口 |

初期不要求 ACT 和 π0.5 共用同一组 MLP 权重。接口和特征可以随实验演进，
最终发布时应明确各 checkpoint 的适配策略和训练设置。

## 方法来源

灵感来源为用户提供的 *Adaptive Action Chunking for Robotic Imitation Learning*。
原论文作者、正式链接和版本尚待核对。后续应补充原方法与本项目在特征、目标、
训练方式及执行机制上的对照；实机平台与策略扩展本身不自动构成创新结论。

离线动作一致性或阶段边界可作为标签设计的研究方向，但其预测准确率不能替代
实机成功率。具体方法与结果确定后再更新本页。
